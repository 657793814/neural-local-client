# shared/prompts

客户端与服务端共用的提示词**源文件**。当前落地范围：

| 文件 | 用途 | 谁在用 |
|---|---|---|
| `question.system.json.md` | 只输出合法 JSON、公式 `$...$`、反斜杠写两个 | 本地客户端（`llm/prompts.rs` 编译期 `include_str!`） |
| `question-pack-skill.md` | 「用 AI 转换」里可一键复制的题目包转换提示词 | 本地客户端 |

`server/src/main/resources/prompts/` 里已有的识别 / 出题 / 归类提示词**暂未搬过来**：服务端的截图链路是「一图一题」，客户端要求「一图多题先切分」，两边行为不同。等两边口径真正统一（方案 §12.1 的 P0 后半段）再迁，避免为了「看起来同源」把服务端改坏。

新增共享提示词时：

1. 只放真正两边一致的段落，不要为了抽象而抽象；
2. 在客户端用 `include_str!` 引入，不要复制粘贴；
3. 内容变更要同时考虑已发布客户端：提示词随安装包走，改了就要求发版。
