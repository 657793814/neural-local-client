# 备份与换机

## 题库就是一个文件夹

默认在 `文稿 / NeuralKB-Local`：

- `neuralkb.db`：题目、标签、知识点关联、班级与作业；
- `assets/`：题目里的图片，按题目 id 分目录；
- `tmp/`：截图、PDF 翻页、格式转换的中间图；
- `backup/`：「导出整库备份」生成的文件。

## 空间占用与清理

设置 → 「本机存储」会把这几类分开算，并给出磁盘剩余：

- **临时文件（`tmp/`）**：截图、PDF 页渲染、HEIC 转换的中间图。识别完、入题时就复制到 `assets/` 了，
  原件随时可清。点「清理临时文件」即可；最近 10 分钟内生成的会留着，避免删掉正在识别的图。
- **题目图片（`assets/`）**：题干和解析引用的图，删了题目会缺图，备份与导出也会少图。
  这里**没有删除入口**，只有「清理无主图片」——那种文件在盘上、但没有任何题目引用（导入中断、
  题目彻底删除时漏下的），删掉不影响任何题目。
- **备份包（`backup/`）**：只保留最近 3 份，更老的可以一键清。

`neuralkb.db` 不会出现在清理范围里。

## 数据库有账号密码吗

没有。本地题库是 SQLite 单文件，打开文件就能读写，不存在「连接用户名 / 密码」这回事。
要防的是别人拿到这台电脑：用系统账户密码、锁屏和「文件保险箱」磁盘加密。
应用自己的登录密码是另一层——argon2id 哈希存在 `local_user` 表里，忘密码没有找回入口，
只能换一个数据目录重新开始（见「本地账号」那页）。

## 备份

设置页点「导出整库备份」，得到一个 ZIP，含数据库与全部图片。放到移动硬盘或另一台机器都行。

## 换机

1. 新机器装好客户端，**先不要录入**。
2. 把备份 ZIP 解压到任意目录。
3. 设置 → 「更换目录」，选中那个目录，应用会复制并重启。

也可以直接用访达把旧机器的整个数据文件夹拷过去，效果一样。

## 恢复

想回到某个时间点：把备份解压到新目录，再「更换目录」指过去。原来的目录不动，确认没问题再自己删。

## 注意

- 别在应用运行时手工改 `neuralkb.db`，SQLite 有 WAL，容易读到半截。
- 备份包含全部题目图片，体积可能不小；图片多的库可以定期清 `tmp/`，但 `assets/` 里的图删了题就缺图。
- 「清理临时文件」也会清掉导入时解压出来的预览副本；如果导入预览正开着，重新选一次文件即可。
