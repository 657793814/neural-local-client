# 班级、学生与作业

这一页把「教谁、布置什么、做得怎么样」串起来，全部存在本机，断网也能批改。

## 先把学生加进来

- **新建学生**：填姓名就行，学号、年级、备注可省。备注可以写「课代表」「需要关注」。
- **学号**：留空会自动编号（1001 起，跳过已用的号），也可以填学校的正式学号。学号在全校范围内唯一：撞号会直接报错，不会把两个人的成绩并成一份。
- **批量导入**：一行一个，**有表头就按表头认列**（`学号` / `姓名` / `年级` / `备注`，顺序随意），没表头就按 `姓名, 年级, 备注` 读；第一列是纯数字、第二列不是（例如 `2026001,张三,七年级`）也认。逗号、制表符、顿号、分号都行，从 Excel 直接粘过来即可。
- 导入前先点「预览」：同名同年级标「已存在，跳过」，学号被占用的标「学号冲突」，其余照常导入，不会把名单刷成两份。
- 学生默认「在读」，毕业或不教了可以**归档**，归档的人不出现在班级添加列表里，但历史作答都还在。

## 建班与成员

- 班级卡片上的**邀请码**点一下就能复制，方便口头或群里发给学生（中心端绑定后用得上）。
- 卡片上的「成员」打开抽屉：可以按姓名搜、从名单里勾选添加、把学生移出班级、重置邀请码。
- **结课**只是把班排到列表后面并标灰，作业和成绩都保留；点「开课」随时恢复。

## 布置作业

1. 在班级卡片点「作业」进到作业列表，点「布置作业」。
2. 先选**考哪些知识点**（可以多选，不选就是整个学科随机）；每个知识点后面的数字是题库里能用的题量。
3. 再填**每个难度出几题**（易 1–2 / 中 3 / 难 4–5），右边会显示这个条件下题库里有多少可用的。
4. 题型可以只留选择/填空/解答；「每题分值」按题型给默认值（选择 3、填空 4、解答 10），改一次就记住，下次还按这个来。
5. 点「生成预览」：逐题能**换一题**（同难度、同知识点另抽一道）、上下移、改分值、移除；需要补题就点「手动加题」搜题库。
6. 补标题、类型、截止时间，先「保存草稿」慢慢改，检查无误再「发布」。发布后题目和分值不再改动，避免成绩对不上。

抽不满时界面会直说「易 3 道只凑到 1 道」，不会拿别的难度顶替——缺题说明题库该补了。

## 收作业

- 作业发布后，学生端（中心）可以直接在线作答；**纸面作业**就在成绩单里点「录入作答」，按题照着学生的答案录入：选择题点选项，其余直接写答案，留空表示没做。
- 保存时客观题立刻判分，主观题进入待批；录错了可以「撤销提交」重新录。

## 批改

- 作业卡片上的「批改 / 成绩」打开成绩单：谁交了、谁没交、待批几题、得分多少一目了然。
- **客观题（单选、多选）提交时自动判分**：单选比字母，多选比集合，大小写和顿号都不影响。
- **填空题与解答题留给老师**：点「批改」逐题看学生答案和参考答案，填分数与评语，点「保存批改」一次保存整份。
- 没手动勾对错时，得分 ≥ 满分 60% 记为答对，规则和中心系统一致。
- 交错了可以「撤销提交」，成绩作废，让学生重做；重新提交后只保留最新一次。

## 讲评清单（批改备注的出口）

- 作业卡片或成绩单里点「讲评清单」，按**题**汇总这份作业：谁错了、错几成、哪个知识点、你写过的批改备注。
- 「先讲这三道」按错的人数排，同错数看得分率——上课前扫一眼就知道先讲哪题。
- 「打印 / 存 PDF」出一页 A4（浏览器里 ⌘P）；「导出 CSV」可以自己再做统计。
- 批改备注只存在这台电脑上（本地没有学生端，学生看不到），它的读者就是这份清单和你自己。

## 常见问题

- **导入后班级里没有学生**：导入只进「学生」名单，还要在班级抽屉里点「从名单添加」。
- **作业发布不了**：至少选一道题；草稿状态不允许学生提交。
- **得分和满分对不上**：作业改过题或分值，成绩单按当前组卷的满分显示。
