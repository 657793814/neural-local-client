# 五分钟录进第一道题

不需要服务器，不需要数据库知识。装好打开就能用。

## 1. 截一张题

按 `⌘⇧O`，屏幕会变暗，拖出要识别的那道题（可以一次框多道）。松手后图片就会出现在「录入」页。

不想用热键也行：打开「录入」，点「截图选区」。

## 2. 让它整理

选好学科，点「开始识别」。模型会把题干、选项、答案拆成字段，通常 30–60 秒。

> 识别会把图片发给你自己配置的模型服务商。没有配置模型时这一步用不了，只录题不受影响。

## 3. 逐题核对

右边每个题目卡片都能单独勾选，列表顶部还有「全选 / 清空」一次勾完。

缺答案、缺解析的题只是标一条浅黄色「待补」，照样能勾上存草稿，复核时再补；
只有连题干都没认出来的题才勾不上，点「编辑」补上题干就行。

## 4. 存草稿

点「存为草稿 N 道」。题目以「草稿」状态进题库的**草稿箱**；
在「题库 → 草稿箱」里复核通过，才算正式入库。

## 接下来

- 已有 Excel / Word 题库：看「批量导入」。
- 想让 AI 出题或自动归类：先看「模型配置」。
- 想放到另一台电脑：看「备份与换机」。
