# 常见问题

## 截图反复要屏幕录制授权

打包版（`app:build` 出的 `.app`）已用固定证书签名，正常只授权一次，之后重新打包也不会再问。仍反复弹授权时：

1. 在项目根目录跑 `bash local-client/scripts/sign.sh --perm-reset`，它会清掉旧的授权记录并打开设置页；
2. 在「系统设置 → 隐私与安全性 → 屏幕录制」里勾选 **NeuralKB Local**；
3. **完全退出应用（⌘Q）再打开**——权限只对新进程生效。

如果是 `npm run app:dev` 从终端起的开发版，授权会记在终端名下、每次重编都变，请用打包版截图。

## 批量补充时反复问「想访问钥匙串」怎么办

API Key 存在系统钥匙串里（SQLite 只存引用，不存明文），读取会触发一次 macOS 授权框。以前的做法是「每调一次模型读一次」，而批量补充是**每道题一次调用**，于是 30 道题连弹 30 次。

现在改为**一个进程只读一次**，之后的调用都走内存缓存：

- 一次归类最多问一次，答「始终允许」后再批量处理不会再弹；
- 在「设置 → 模型」改了 Key、删了模型，缓存会立刻失效，不会用到旧 Key；
- 仍频繁弹窗，说明应用签名在变（开发版常见），换打包版即可；打包版的固定签名只授权一次。

## 截图后识别报「读不了截图」

已修复（截图临时文件不再提前删除）。若仍出现，先确认用的是重新打包后的版本；临时图片现在落在数据目录的 `tmp/` 下，识别会按路径重复读取。

## 提示「没有可用的视觉模型」

设置 → 模型，添加一个勾了「支持图片」的模型，并在「截图识别」用途里排上它。

## 401 / 403

Key 不对或没权限。重新填一次 Key；有些服务商的 Key 只能访问指定模型。

## 429 / 额度用完

换一个候选模型，或等到额度恢复。该模型会自动冷却 2 分钟，不会一直撞墙。

## 识别很慢

模型一次要 30–60 秒。图片越大越慢，先裁掉不需要的部分。超时通常是网络问题。

## 识别结果缺答案

模型没解出来。可以在结果里不勾那道题，手工补录；或换一个更强的模型重试。

## 导入说「只支持 JSON / JSONL / ZIP」

Excel 和 CSV 要先转换。打开「导入 → 用 AI 转换」，复制提示词连同表格发给智能体，让它输出 JSON。

## 导入后提示「缺图」

智能体拿不到原图。用客户端的截图或「编辑 → 配图」补上；文字描述不能代替图。

## 「这道题同步过，不能彻底删除」

同步过的题硬删会在下次同步被拉回来。先在「同步」退出登录，再删。

## 搜索不到

两个字以内会走文本包含匹配，三个字以上走全文索引。仍然搜不到时，试试标签或学科筛选。

## 应用打不开 / 提示数据库被占用

可能开了两个窗口。全部关掉再打开；仍然不行，把 `neuralkb.db` 复制一份留底，再联系开发者。

## 会把我的题目上传吗

不会。只有你主动点识别、出题、归类时会发给**你自己配置的模型**；开启同步并点推送才会到中心系统。应用不收集日志。
