# 学情与错题本

## 掌握度怎么算

一句话：**按时间衰减加权的正确率**。和中心系统同一套公式，同一份作答在两端算出来的分数一样。

```
每道题：weight = 1 / (1 + 距今天数 / 14)
答对：factor = 0.75 + 难度 × 0.05     （难度 1–5，即 0.80–1.00）
答错：factor = 0.05
掌握度 = round(min(100, Σ(weight × factor) / Σweight × 100))
```

含义：

- **越新的作答越算数**。14 天前的作答权重只剩一半，一个月前剩三成——补过、讲过的学生，分数会慢慢爬上来，不会一直被旧账压着。
- **答对一道难题加分更多**；答错几乎归零，所以「错一题」比「对一题」影响大，符合直觉。
- 分档：≥85 **已掌握**；1–84 **在学**；0 **未开始**。
- **待批改的主观题不算**：既不算对也不算错，只在矩阵表头标「N 待批」。老师给完分，数字立刻变。

## 两个视角

学情页顶上分两栏，回答的是两个不同的问题：

| 视角 | 回答的问题 | 适合什么时候看 |
|---|---|---|
| **班级** | 这个班整体怎么样、哪个知识点全班都没吃透 | 备课、讲评、决定下次课讲什么 |
| **学生** | 这个孩子最近怎么样、在班里什么位置 | 找学生谈话、给家长反馈、单独补差 |

学生视角不要求先选班级：默认列出所有学生，也可以按班筛、按姓名搜。

## 班级视图

### 知识点矩阵

- 行是学生，**薄弱的排在前面**，一眼看到谁掉队；
- 列是这个班作业覆盖到的知识点；
- 格子颜色越深掌握越好，`–` 表示这个学生在这个知识点上没有作答（不等于 0 分）；
- 点学生姓名，进入他的个人学情整页。

「还没有知识点列」说明班里的题没挂知识点：去题库给题目补挂，或布置作业时选带知识点的题。

### 共性错题

同一个班做错人次最多的 5 道题，带错误率与知识点。优先讲这些，比逐份翻作业快。

### 关键数字

- **班级掌握度**：交过作业的学生的平均掌握度（没交的不拉低平均，单独算未开始）；
- **得分率**：已判分作答的 `得分 / 满分`；
- **待批改**：整班还没给分的题数，点「去批改」直接跳到这个班的作业。

## 学生名单

一行一个学生，横向比人：

- **掌握度**：横条 + 分数，颜色与班级矩阵同一套；
- **变化**：近两周掌握度涨跌（正数是进步），不是历史总分；
- **薄弱知识点**：低于 70 分的知识点，最多列三个；
- **提醒**：待复习错题数、待批题数、最近一次练习日期。

排序默认「薄弱优先」；也可以按**退步最多**（先找滑坡的）、**待复习多**（先催复习）、**最久没练**（先找回手感）排。

顶部六个数字是名单的整体画像：名单人数、有数据人数、薄弱人数、已掌握人数、待复习题数、超过两周没练的人数。

## 个人学情

点名单里任意一行，进入这个人自己的整页。从上到下：

1. **位置**：掌握度、近两周涨跌、班内名次（第几 / 多少人）、班级平均分，以及「高于 / 低于班均多少分」。只有交过作业的同学参与排名，没交的不算拖后腿。页头会带**学号**，和成绩册对得上。
2. **学情诊断与本周安排**：结论、优势、卡在哪、这周每天做什么、给家长的一句话。见下一节。
3. **先补这几个**：掌握度低于 70 的知识点，按薄弱程度排序，直接给「找同类题」入口。
4. **近 8 周掌握度**：每周把「到那周为止」的作答重算一遍，看的是趋势，不是快照。
5. **作业与考试**：把两类分数**统一换成百分制**后放在同一根轴上——圆点是作业（按题汇总的得分率）、
   方块是考试（整卷总分）。100 分小测、150 分月考、10 分练习放在一起也不会失真；缺考不进时间轴。
6. **知识点明细**：薄弱的排前面；没有作答的知识点排在最后并标「未作答」，不会伪装成 0 分。
7. **错题本**：见下。
8. **考试成绩**：最近 12 次的分数、班内名次、班均；录分在「成绩」页。
9. **最近作业**：每次提交的得分、待批数、是否迟交。

页头右上角的「家长周报」会把这一页的内容压成**一张 A4**：位置、一句话结论、优势与短板、两张趋势图、
最近记录、本周安排、给家长的话，末尾留了家长反馈与签字的位置。点一下交给系统浏览器，
按 ⌘P 打印，或「存储为 PDF」发给家长。周报只带数字与结论，不带题目原文。

## 学情诊断与本周安排

个人页顶部那张卡，回答的是「所以现在该做什么」。

**两层，先后有序：**

1. **规则版**（永远可用，不联网）：把掌握度、薄弱知识点、到期错题、最近考试翻译成一张周计划——
   周一复习到期错题、周二周四各补一个薄弱点、周五综合小练、周六回看错题、周日休息。
   每天 10–25 分钟，任务具体到「看 1 个例题，再做 8 道同类题」。
2. **AI 版**（可选）：点「AI 诊断」，把同一份**结构化数字**（不是题目原文、不是聊天记录）交给模型，
   让它在规则之上补「为什么卡在这里」「怎么跟家长说」。输出仍然是同一套结构，AI 不合格就退回规则版。

**几条硬规矩：**

- 模型只拿到姓名、掌握度、题量、名次、分数这类信息，拿不到题目原文，也拿不到聊天记录；
- 模型输出要过结构校验：缺字段、少天数、任务为空，都退回规则版，不会把半截话给老师看；
- 报告按**数据指纹**缓存：数据没变不重复调用；有新作答或新分数后，卡片上会提示「数据已更新，建议重新诊断」；
- 没配模型、断网、模型报错，都**不弹错误**，直接用规则版，页脚会写明来源。

**依据**默认折起来（卡片底部「依据 N 条」）。结论要能追溯，但不该让人先读十行数字。

## 错题本

规则：

1. 作业判分为**错**时自动入本；主观题在老师给分后按对错入本；
2. 同一题反复做错只累加「错 N 次」，不会出现一排重复；
3. 后来**做对了自动结案**（状态变「已掌握」），记录留着可查，不再催复习；
4. 状态三档：**待复习 / 复习中 / 已掌握**，可手动切换，也能直接移出。

复习节奏：入本次日提醒；点「复习过」后隔 3 天，再往后隔 7 天。「已掌握」就停催。

错题本是**每个学生一份**，在个人学情页看，不跨学生混在一起。

## 常见问题

**为什么某道题做错了却没进错题本？**
主观题要等老师给分才判对错；还没批的不会入本。

**为什么名单里没有某个学生？**
名单只列「在读」的学生。已退班或被删除的学生不进名单，但历史学情还在，跟着学生档案走。

**学生退班了，学情还在吗？**
在。学情跟着学生档案走，退班只影响班级矩阵里的行。

**能不能按知识点筛题库？**
可以，题库页的知识点筛选与这里同源；看到薄弱知识点，点「去题库找同类题」即可。
