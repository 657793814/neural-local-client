# 成绩单

## 和「作业」有什么不一样

| | 作业 | 成绩（考试） |
|---|---|---|
| 分数怎么来 | 按题判分，系统自动汇总 | 整卷一个总分，老师直接登 |
| 适合什么 | 平时练习、单元作业、拍照批改 | 月考、期中期末、单元测 |
| 明细 | 每道题的对错、知识点 | 一个人一行：分数、名次、班均 |

作业成绩在「作业页」和「个人学情 → 最近的作业」里看；这里是纸笔考完直接登分的场景。

## 建一次考试

点右上角「新建考试」，填：

- **名称**：例如「第一次月考」；
- **班级**：成绩挂在班级上，同一个班可以有多场；
- **类型**：考试 / 小测 / 单元测，只影响标签；
- **满分**：默认 100，150 分制直接改成 150；
- **及格线 / 优秀线**：留空就按满分的 60% / 85% 算。改满分不会把已经录好的分数带歪；
- **日期**：默认今天，可以补录上个月的考试；
- **备注**：范围、难度、是否计入期末。

同一场考试的信息随时能改（右上角「改考试信息」），改完分数不动。

## 登分

- 名单按**学号**排序，和纸质成绩册顺序一致；没有学号的按姓名排；
- 直接点分数格输入，**按 Enter 跳到下一个人**，可以一路敲到底；
- **空着 = 缺考 / 还没录**，与 0 分严格区分：0 分会拉低平均，空着不会；
- 改过的行会变黄，右下角「保存成绩」才进统计；「放弃改动」恢复成保存前的值。

保存时前端会先校验：非数字、超出 0–满分 的分数都会点名到人，不会整批失败。

## 批量登分（粘贴 / 导入）

一个一个敲太慢时，在「登分」卡片点 **粘贴 / 导入**：

- 从 Excel / WPS 表格里选中几列直接复制，粘到输入框；或者点「选择 CSV / TXT」读本地文件；
- 点 **预览匹配**，每一行会显示匹配到的学生、分数和状态；确认后点 **填入登分表**；
- 填入的是**草稿**（行会变黄），还要点「保存成绩」才真正生效。

支持的写法：

```
学号,姓名,分数
2026001,张三,92
2026002,李四,85.5
2026003,王五,缺考
```

- 分隔符：Excel 复制的 **Tab**、CSV 的**逗号**、分号 / 顿号、空格都认；
- 表头可以省略。有表头时按列名认（学号 / 姓名 / 分数 / 备注）；没表头时先按学号对名单，分数取学号后面的数字列，两列「学号 + 分数」最简单；
- 学号支持全角数字、前后空格和 Excel 误加的 `.0`（`２０２６００１` 等价于 `2026001`）；学号对不上时，**唯一姓名**也能兜底匹配，预览里会标「按姓名匹配」；
- 空着 / 写「缺考」「未考」「-」都当作缺考（与 0 分不同）；重复的学号只取第一行。

预览状态：**匹配**可勾选填入；**名单里没有这个学号**、**分数不是数字 / 超出满分**、**重复**的行默认不填，取消勾选还能跳过任意匹配行。名单里没出现的人不会被改到——导入只覆盖本场考试名单上的学生。

## 统计口径

- **平均分 / 中位数 / 最高 / 最低**：只算有分数的人，缺考不参与；
- **及格率 / 优秀率**：分母是「有分数的人数」，不是班级总人数；
- **分数段**：按满分百分比切五档（不及格 / 60–69 / 70–79 / 80–89 / 90+），100 分制和 150 分制形状可以直接比；
- **名次**：并列同名次（92、88、88 记作 1、2、2），缺考没有名次；
- **与班均**：正数是高于平均，负数是低于。

## 导出

「导出 CSV」把当前这张表存成 CSV（学号、姓名、分数、满分、名次、与班均、备注），带 BOM，Excel 和 WPS 打开都不乱码。

## 和学情的关系

- 个人学情页的「考试成绩」卡片：最近 12 次分数、班内名次、班均，一眼看分数曲线和掌握度是否同向；
- 学情诊断（个人页顶部）会把最近一次考试作为依据之一：分数掉了但掌握度没掉，多半是这次卷子难或状态问题；两个一起掉，才需要调整计划。

成绩只存在本机，不上传；同步中心题库时也不带成绩。
