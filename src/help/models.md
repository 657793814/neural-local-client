# 模型配置

应用**不内置模型，也不预置厂商模板**。你填自己的 OpenAI 兼容端点，可以加多个。

## 三个字段怎么填

- **Base URL**：服务商文档里的接口地址，通常以 `/v1` 结尾，例如 `https://api.example.com/v1`。本地 Ollama 填 `http://127.0.0.1:11434/v1`。
- **模型名**：填完地址和 Key 后点「拉取列表」，直接从服务商读回全部模型 ID 挑一个，下拉里能按关键字过滤；读不到（或想用别名）时照样可以手填。编辑已有模型时不重填 Key 也能拉。
- **API Key**：只写进 macOS 钥匙串。设置页只显示「已保存」，读不回来。

## 支持图片

只有勾了「支持图片」，截图识别才会挑它。没有视觉模型时，「录入」会明确提示去添加，而不是静默失败。

## 用途路由

用途各有自己的候选队列，在「设置 → 模型」里排：

- 对话 / 截图识别 / AI 出题 / 归类与解析 / **AI 制图（通用示意图）** / **GeoGebra 制图（数学精确图形）** / 图片修复 / 批改抄录 / 学情建议 / 课件相关。

「AI 制图」和「GeoGebra 制图」分别对应生成页里制图弹窗的「通用示意图」和「数学精确图形」两种模式：通用模式画各学科示意图，数学模式强调坐标系、几何关系与关键点标注。两者都产出矢量 SVG，离线可渲染、不打包外部图形引擎。可以为两种模式各排一个擅长绘图的模型。

排在前面失败会自动换下一个。遇到 429 或额度错误，该模型冷却 2 分钟；全部冷却时仍然会试一次。

## AI 制图怎么用

在「生成」页的 AI 出题预览里，每道题右上角有「AI 制图」；在「录入」页手工录题的「配图」区也有。填题干（或一句话描述）、选图形类型、点「生成图形」，预览满意后插入。图随即作为题目配图保存，导出、备份、复制题目都带着走。生成的图先由模型写成 SVG，应用会过滤掉脚本和外链后再显示，只保留纯矢量图形。

## 测试连接

每个模型后面有「测试连接」，发一条极小的请求，显示延迟或错误原文。错误原文可以复制，方便对照服务商文档。

## 常见错

- **401 / 403**：Key 不对，或这个 Key 没有该模型权限。
- **404**：Base URL 少了 `/v1`，或模型名拼错。
- **429 / quota**：额度用完或限速，换一个候选模型。
- **超时**：图片太大或网络差，先裁小截图。
