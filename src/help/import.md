# 批量导入

## 支持什么

只支持三种文件：

- `questions.json`：一个题目包；
- `questions.jsonl`：一行一题，适合几千题的大包；
- `.zip`：`questions.json` + `images/` + `README.txt`，图片跟着走。

**不解析 Excel / CSV**。手里是表格时，用「用 AI 转换」把提示词连同表格发给智能体，让它转成 JSON 再导入。只有一套校验口径，就不会出现「表格能进、JSON 进不去」。

## 预览里四种状态

- **可导入**：字段齐全。
- **重复**：题干指纹与题库里某道题完全一致。
- **相似**：字符相似度 ≥ 86%，可能是同一题的变体。
- **无效**：缺题干、缺答案、缺知识点，或图片路径不安全。红字会写清哪一条不满足。

重复和相似默认不勾选。确实要保留时，先手动勾选，再在「仍然导入重复或相似题？」确认框里点「仍然导入」；没有这次确认不会导入它们。无效题不能导入。

取消预览或另选一个题目包，会清理本次预览解出的临时文件，不影响已经导入的题目。

## 图片

按三处顺序找：`images` 数组 → 题干 / 选项 / 解析里的 `![](images/x.png)` → `images/` 目录下的同名文件。选项本身是一张图时也按这条规则导入，不会变成空选项。

只接受 jpg / png / webp / gif，按文件头判断，不看扩展名。ZIP 里有 `..`、绝对路径或符号链接会整包拒绝。

## 撤销

「导入历史」里点「撤销这一批」，这一批的题全部移到回收站，可以再恢复。数据库里不会留半截数据。

## 智能体没给出图片

它会在 `missingImages` 里写「图1」。导入后题目会带提示，需要你补图——不会用文字描述糊过去。
