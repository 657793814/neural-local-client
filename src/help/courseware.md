# 课件

课件 = **讲义式课件**：围绕知识点讲授的教学材料——知识清单、例题精讲、变式拓展、拔高挑战、
思维训练、小结与作业。可以导出 HTML、Word、PPT、PDF 和 JSON 草稿；文件生成、图片处理与预览都在本机完成。

> 与知识库里的 3D 交互仿真课件不是一回事。仿真课件（抛体、海陆风之类）用 `courseware-lab`
> 做，成品照样可以「导入 HTML」进这个库来管、来布置。

## AI 生成课件

1. 顶部「AI 生成课件」，填写课题、学科、年级、课时、学生情况、教学目标和重点难点；
2. 「内容结构」可选**常规课程**或**专题课程**，两者只切换默认大纲，最后都进入同一个编辑器；
3. 在「素材与输出」中设置例题/练习数量、参考内容、目标文件类型和自定义变量；
4. 需要图片时点「添加图片」。每张图可填图号、说明、使用位置和「必须使用」，图片会立即复制到课件草稿目录；
5. 右侧提示词可整段修改。手改后，调整变量不会覆盖它；点「重新套用模板」才按当前变量重建。

提示词有两种用法：

- **调用本地配置的模型**：使用模型池的「课件生成」用途。纯文字模型只收到图片清单；需要识图时，
  在「附图给视觉模型」里选一张图。生成结果只是草稿，必须校对后才入库；
- **复制给其他智能体**：点「复制提示词」，再点「打开图片目录」，把图1、图2等对应图片一并提供。
  对方返回 `HandoutSpec` JSON 后，粘贴到「外部智能体的 JSON 回传」解析。没有文件工具的智能体不能直接交付
  真正的 Word、PPT 或 PDF，回本机校对后再导出。

「保存草稿」会保存变量、手改提示词和原始模型返回。模型返回无法解析时，原文仍保留，上一份成功草稿不会被覆盖。

## 导入现有讲义

顶部「导入现有讲义」支持一次多选 DOCX/DOCM、PPTX、PDF、Markdown、TXT 和 HTML。

- **仅统一格式（默认）**：只整理标题、讲解、例题等结构，不改写教学内容、不补答案；
- **整理并优化**：允许 AI 润色和补全，新增或实质改写会列在校对页，老师逐项确认；
- 不启用 AI、模型未配置或调用失败时，仍保留本地抽取文字与待校对草稿；
- 每份文件独立显示等待、解析中、待校对、失败、重复和已入库状态，单份失败不阻塞整批；
- 失败项可单独重试；重复文件只有在明确确认后才再次导入；
- 点任务可对照原稿抽取文字、待校对内容和 AI 原始返回，也可打开受管原稿。

PPT 动画、SmartArt、复杂公式与模糊扫描件不保证一比一还原，页码或幻灯片编号和警告会留在校对页。

## 手动新建与 AI 补题

「手动新建」保留原有编辑方式：知识清单、例题、变式、拔高、思维训练、小结与作业都可手写。
例题可「挑题」挂本地题库，编译时把题干、答案和解析内联进讲义，同时保留题目挂接。

编辑器里的「AI 补题」仍以第一道例题为锚点，只补变式、拔高和思维训练草稿；过目、改写或删除后再编译。

## 校对、入库与导出

AI 生成、外部 JSON 和现有讲义导入都进入同一个校对编辑器。可以修改正文、答案解析、知识点、
教学要求与图片，也可以先「保存校对草稿」。点「校对完成，生成课件」后才编译入库。

入库仍过**五道闸**：结构与必填 → 题目引用与题干 → 篇幅与体量 → 打印可用 → 产物自检。
哪条没过会写明原因，不会生成一份看似成功的空课件。

课件卡片的「导出」支持：

- **HTML**：单文件，断网可看、可投屏、可打印；
- **DOCX / PPTX**：本机生成真实 Office 文件，文字与图片不依赖原图位置；
- **PDF**：优先调用本机 Chromium 打印；没有可用浏览器时打开预览，改用系统打印面板的「存储为 PDF」；
- **JSON**：备份统一草稿，便于外部智能体回传和再次整理。

所有导出都通过系统保存框选择位置，同名文件不会被静默覆盖。旧 HTML 导入课件没有统一草稿，只能导出 HTML 或 PDF。

## 导入 HTML

把自己已有的单文件 HTML（讲义、仿真课件、第三方成品）导进来统一管理。导入时静态扫描：

- 含外链脚本 `<script src="http…">` 的**直接拒**，断网打不开；
- 含其他网络地址 / fetch 的给提示，不拦；
- 同一份文件（按内容哈希）不会重复入库。

## 预览与布置

- 「预览」在隔离 iframe 里打开，不进主窗安全策略；打印时解析自动展开、分页不切断题目；
- 「布置」选班级、可设截止时间；取消布置点班级名旁的 ✕。

## 数据在哪儿

- 课件 HTML：`数据目录/assets/courseware/<id>.html`；
- 正式课件图片：`数据目录/assets/courseware/<id>/images/`；
- AI 工作台图片：`数据目录/assets/courseware/drafts/<draft-id>/`；
- 导入原稿：`数据目录/assets/courseware/imports/<task-id>/`；
- 元信息、统一草稿、题目挂接和导入任务：本地 SQLite；数据库只存受管文件的相对路径；
- 「清理无主图片」不会删除上述课件图片和导入原稿。
