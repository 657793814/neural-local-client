# 批改台（拍照批改）

纸质作业收上来，用相机拍成照片，在软件里逐题给分。**不另起一套批改系统**——照片是挂在原来那份作业、那个学生、那道题下面的附件，批改完学情和错题本照常更新。

## 什么时候用

- 学生用纸笔写的作业，老师拍成照片带回电脑；
- 或者学生拍照提交，但老师想在本地留一份原图对照。

在线提交（学生自己在软件里答的）仍然走原来的批改抽屉，两条路殊途同归。

## 一条线走下来

```
导入整页照片  →  切题  →  挂到第几题  →  逐题给分  →  保存
```

### 1. 导入整页照片

在「批改台」选好班级和作业，点队列里的学生，再点「导入照片」，一次可以选多张。

手机里的照片不用先传到电脑：点旁边的「手机上传」，会出现一个二维码。

1. 手机相机扫二维码（手机和电脑连同一个 WiFi）；
2. 手机上拍照或从相册选，可以一次选多张；
3. 传完点「停止上传」，照片已经躺在左边的照片墙里。

手机端会先把照片缩到长边 2200px 再发（一张通常不到 1MB），所以 iPhone 的 HEIC、几 MB 的原图都不用先转换。照片只在这台电脑和你手机之间走，不经过任何外网服务。

照片存到数据目录的 `assets/submissions/<学生 id>/`，属于「作答附件」，**不会被「清理临时文件」或「清理无主图片」删掉**——只有你自己在界面上点删除才会消失。

### 2. 切题

点整页照片下的「切题」：

- 软件会先自动找出几块候选题块（图上带编号的蓝框）；
- 点一个蓝框就选中；
- 自动找的不准，就在图上**直接拖一个框**，框哪儿取哪儿。

选好之后：

- 「挂到第几题」选好题 → 切出来的块直接挂上去；
- 或者选「先不挂」→ 切出来放在左边面板里，回头再挂。

切出来的一块会记住**它来自哪张整页、在整页的哪个位置**，随时能回去看原图。

### 3. 逐题给分

右边是逐题卡片：题干、学生答案、参考答案、这道题挂着的照片、得分和评语。答案里的公式是画出来的，不是 LaTeX 源码。

**每题的满分来自作业里的题分**（布置作业时每题那个分数框），不是题库里的固定值——同一道题放在不同作业里分值可以不同。所以想给 8 分却提示「不能超过 1 分」时，去作业里把这题的题分改掉。

「批改备注（仅本机）」只存在这台电脑上：本地没有学生端，学生看不到。它的出口是**讲评清单**——作业卡片或成绩单里点「讲评清单」，你写的备注会按题汇总，上课前扫一眼就知道先讲哪道。

左边面板里还没挂题的块，下拉选一下就能挂过去；挂错了在题块上点 ✕ 删掉。

### 4. AI 抄录建议（可选）

点了「AI 抄录这一张」，视觉模型会把照片里的手写内容**抄成文字**，再给一个建议分和一句评语。

规矩很硬：

- **抄录是逐字的**，看不清的地方写「□」并说明，绝不改写、补全、润色学生写的内容；
- **建议只是建议**。分数和评语必须你点「用这个建议」才写进批改记录，否则什么都不改；
- **原图永远保留**，模型不动它。

要在「设置 → 模型」里给「批改抄录」这个用途排一个支持图片的模型。不排也能用，会退回所有启用模型里支持视觉的那个；一个都没有时会明确报错，不会瞎猜。

## 纸质作业没有在线提交怎么办

学生压根没在软件里答过题很正常。批改台打开这个学生时会自动替他建一次**空提交**——每道题一行，全部标成「待批」，分数空着。

建完之后：

- 照片有地方挂了；
- 给完分，学情照常重算；
- 错题照常进错题本。

重复打开同一个人不会重复建提交。

## 待批队列

左边的队列按「待批的排前面」排。顶部有：

- **上一份 / 下一份**——一份一份批过去，不用回队列里点；
- **N 份待批**——一眼看到还剩多少。

每个人名字后面有徽标：`待批 N` / `已批` / `未交`，以及照片数（📷）。

## 常见问题

**自动切题切歪了。** 手写卷子的行距不规，自动检测本来就只给个大概。直接在图上拖框最靠谱。

**一张照片上有几道题。** 自动检测会分块，一块一题。分得不对就手动框。

**照片导入后不见了。** 检查是不是在别的学生名下——照片按学生分目录存着。也检查左边队列里该学生的 📷 数字。

**AI 抄录看不清。** 建议卡片会标「看不太清」并在 warning 里说明哪一处。换个角度重拍一张更正的，或者老师自己看照片给分。

**照片占空间。** 「设置 → 本机存储」能看到 `assets` 的占用。作答照片属于 `assets` 里的一部分，要清就在批改台里删具体照片。

**手机上传传不上去。** 页面上会写清是哪一步：

- 「连不上这台电脑」→ 手机和电脑不在同一个 WiFi，或者电脑上那个「手机上传」窗口已经关了/过 15 分钟了；
- 「这张照片太大了」→ 手机端压缩没成功（少数机型），换一张或用「导入照片」；
- 「图片格式不支持」→ 极少见的 HEIC 变体，在手机相册里先「编辑 → 存为新照片」再传。

实在不行就用数据线或隔空投送把照片拷到电脑，再用「导入照片」——效果一样。

## 相关页面

- 班级 → 作业：布置作业、看提交情况，页头有「拍照批改」入口；
- 学情：知识点矩阵、错题本，批改完的数据会同步过来；
- 设置 → 本机存储：本机空间占用与清理。
