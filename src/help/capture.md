# 录入 · 采集台

「录入」页顶上**三个页签**，按你手里有什么来选：

| 页签 | 适合什么 |
|---|---|
| **本地 / 截图** | 本地 PDF / Word / 文本 / 图片文件、`⌘⇧O` 截屏、`⌘V` 粘贴、连拍整卷 |
| **网页取题** | 在线试题站，打开网址后直接抓网页里的题块（题干 / 选项 / 答案 / 解析），或截取当前页 |
| **粘贴文字** | 电子版题目、纯文字网站，可以直接贴文本 |

三个页签共用右边的「识别结果」——切页签不会弄丢已经认出来的题。

## 一、本地 / 截图

拿原文的几种方式，随便挑一种：

1. **热键** `⌘⇧O`，拖出选区；Esc 取消。
2. **粘贴** `⌘V`，一次可以粘多张。
3. **打开文件**：选图片、**PDF**、**Word**（.docx/.doc）或**纯文本**（.txt/.md 等）；也可以直接把文件从 Finder 拖进窗口。Word 和文本文件会自动跳到「粘贴文字」页签，点「整理成题目」即可。

### 打开 PDF

下载来的整卷多是 PDF，不用先转图：

- 打开后会出现**页码条**，点数字直接跳页；本机渲图，不联网。
- 自动切到**精细模式**——整卷要按页裁，连拍在这里没意义。
- 页面按栏宽铺满，字看得清；一页比窗口高就在取景区里滚，不会把右上角的按钮顶出去。
- **打开就自动找题块**：本机按行投影把这一页切成一道道题，画成浅蓝虚线框，左上角有编号。
- 要精确框选或看细节，点「放大」，在浮层里点题块或自己拖框，点中后会回到主视图。

### 点一块，就识别这一道

打开页面后不用先点什么按钮：

1. 页面上已经盖好了题块框（浅蓝虚线）；不想要就点「重新找题块」再算一次。
2. **点一下某块** → 变成实线深蓝，只亮这一块；底部提示「已选第 N 题」。
3. 点「识别这道」→ 自动裁下这一块并送去识别，不用先进队列。
4. 想一次处理多块：按住 `⌘` 或 `Shift` 点选，然后「裁下选中块入队」，最后在连拍队列里「识别全部待处理」。
5. 不选任何块直接点「识别这张」，就是整页识别。

这套找块是纯本地像素运算（Otsu 阈值 + 行列投影），不联网、不花模型额度。
两栏排版、大段手写容易切歪，这时用「框选」自己拖一个框更稳。

### 选识别方式：本机 OCR / AI 识图 / 自动

图片识别有两种引擎，在「识别方式」里选：

- **自动**（默认）：先用 **本机 OCR**（macOS 自带 Vision，离线、不花模型额度）；
  读不到文字或整理不出题干时，再自动交给「AI 识图」，并在题卡上标一句原因。
- **本机 OCR**：只走本机，断网也能用。文字题又快又稳，整页公式图可能认不全。
- **AI 识图**：把图片发给你配置的视觉模型，图片题、公式、复杂版面更稳。

本机 OCR 会按题号切题、拆选项，并认出「答案 / 解析 / 知识点 / 难度」这些标记；
认不出题号时至少把整段文字当成一道题干，不会整张丢掉。

保存图片识别结果前，会先检查本次勾选题目的全部原图。只要有一张原图缺失、读不了或格式不支持，这次就整批不保存；按提示重新识别后再存，不会留下半批草稿。

### 跨页的题怎么处理

一道题被翻页截断时（题干在上一页、选项在下一页），分开识别只会得到半道题。
**不要**把两整页直接拼起来——页眉页脚和上半页已认过的题都在里面，模型十次有八次只认一半。
按下面两步走，每页只取真正需要的那段：

1. 在**上一页**框出这道题的下半段（题干在页尾时，从题号框到页底）；
2. 点「跨页拼接」——上一页那段先被裁下来，画面自动翻到下一页；
3. 在**下一页**框出接着的部分（选项、下一段题干），不框就是整页接上；
4. 点「接上并识别」：两段竖着拼成一张，中间留一条白缝，直接送去识别；
5. 题目还长就再点「再拼第 N 页」，每多一页只多取那一段；
6. 想反悔点「取消」，回到单页。

拼接出来的图也能「框选」再裁一刀；识别结果照常进右栏。

### 一页一页认，结果不会丢

右栏的结果是**按页存**的：认完第 1 页翻到第 2 页，第 1 页的结果还在内存里；
翻回去会原样回来（连你勾了哪几道、改过哪道题都在），标题旁边会提示「上次的识别结果已恢复」。
所以可以先把整卷每页都认一遍，再从头逐题存草稿，不必一次认完就立刻存。

### 连拍

打开「连拍」，之后每次截图 / 粘贴图片都**直接进队列**，取景区只显示最近一张并标「已入队」。
翻一页按一次 `⌘⇧O`，十几张图排好，最后「识别全部待处理」。

关掉连拍就是**精细模式**：图留在取景区，先看清晰度，再决定整卷识别、裁块入队，还是跨页拼接。

队列平时收成一条（`连拍队列 · 2 张待识别`），点开才占地方：

- **待识别** → 「识别全部待处理」，一次跑完整队；
- **失败** → 单张「重试」，不影响其它张；
- **已识别** → 「清理已完成」，把队列腾干净。

截图只用于这一次识别，**不会存进题目**，识别完就可以清理。题干和选项里真正用到的图会单独裁出来存进题库。

## 二、网页取题

- 填网址按回车，网页直接显示在录入页里（不再另开窗口）；取过题的网址自动记进来源，`☆` 置顶、`×` 忘掉。
- **先在左上角选好学科**，网页里抓到的题就归到这个学科；之后换学科会自动同步。
- 网页里翻页、登录都在这一块完成。切到别的页签时网页会暂时藏起来，回来还在原页面，登录态不丢。
- 站内链接如果是「新窗口打开」，会自动改成在内嵌页里直接跳转，不会点了没反应。
- 页面右下角会浮出「**📝 识别本页 N 题**」，每道题上方还有一个小按钮「**收这题**」：
  - 点「收这题」只收这一道；
  - 点「识别本页 N 题」收当前页所有能认出的题，回主窗右侧逐题核对；
  - 一次最多收前 60 道。页面题数更多时会显示总题数，手动翻到下一页后继续。
- 抓的是当前页**看得见的结构化字段**：题干、选项、答案、解析、知识点、难度。隐藏答案和隐藏模板不会混入，公式优先保留 MathJax / KaTeX 源码，来源记录当前页面的真实网址。
- 题里有可见图片时会提示「含图片，请用截图补图」；网页取题不会替你下载图片。
- 顶部「识别本页」和页面里的浮动按钮是同一个动作；失败会直接提示，可以重试。
- 页面改版、脚本认不到题块时，会把整页可见文字填进「粘贴文字」文本框。**这时不会自动调用模型**；检查文字后再点「整理成题目」，才会走文字识别。
- **截取图片**：框选截图走识别引擎——适合图片型题目、公式图。
- 只处理你主动打开的当前页，不自动爬站或翻页，也不绕过登录、验证码或付费墙。被挡住时可改用系统浏览器打开，再按 `⌘⇧O` 截图。

## 三、粘贴文字

把题目文字贴进去，一次多道按题号分隔，点「整理成题目」。

这条路走对话模型，**不需要视觉模型**，纯文字网站、电子版试卷很合适。

## 四、右边：逐题核对，改好再存

识别结束后，右边的题一道一张卡片：

- **缺答案 / 缺解析 / 缺知识点**的题只是标一条浅黄色「待补」，**照样能勾上存草稿**——
  草稿箱本来就是放半成品的地方，这些留到复核时补；
- 只有**连题干都没认出来**的题才勾不上（红色提示），点「编辑」补上题干，或者直接丢掉；
- 列表顶部有「已选 N / M 道 · 全选 · 清空」，可以一次勾完再存；
- 点卡片右上角的「**编辑**」，就地改题型、难度、题干、选项、答案、解析、知识点；
- 保存后待补清单立刻重算；
- 改好点「**存为草稿 N 道**」，会告诉你其中几道还待补。

保存后若有题目未存，页面会列出原因并保留原文，不会自动翻到下一页；重新识别后只勾选还没存的题。题干或选项里有图形时，识别会把那块图裁出来随题保存；截图本身不入库，可在「设置 → 存储清理」里清掉。

> **存草稿不等于入库。** 存下来的题带「草稿」标记，进题库的**草稿箱**；
> 在草稿箱里补齐答案、解析和知识点，复核通过才算正式入库。AI 与识别出的题不会未经人眼就进正式题库。

## 五、还是存不进去怎么办

- **重截 / 重裁**：裁得更紧、更清楚，或者用拼接把跨页的题连起来；
- **就地编辑**：右边那道题点「编辑」，自己补答案与知识点；
- **手工补录**：点右上「手工录题」；
- **换模型**：设置里给「截图识别」用途排一个更强的视觉模型。

## 六、隐私

- **本机 OCR** 完全在本机运行，图片不出这台电脑；
- 只有选「AI 识图」（或自动模式回退）时，图片才会发给你配置的模型服务商；
- **结构化网页取题**只在本机解析当前页 DOM，不上传整页；识别不到题块时，整页文字也只先填进本机文本框，只有你检查后点击「整理成题目」，文字才会发给你配置的对话模型；
- 本地题库不会上传；没开同步且不使用模型时，任何内容都不离开这台电脑。
