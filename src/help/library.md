# 题库

所有题目都在本机的一个文件夹里，断网也能查、能改、能导出。

## 四个列表

页头的切换条把题目分成四个**互不重叠**的列表：

- **题库列表**：已经复核通过的正式题；草稿和驳回的题都不会混进来。
- **草稿箱**：识别、AI 出题、手工录入后还没复核的题。
- **驳回列表**：复核没通过、写了驳回原因的题；改完可以「转回草稿」重新复核。
- **回收站**：删掉的题，可以恢复或彻底删除。

切列表会清掉当前搜索和筛选条件，避免「在回收站搜了半天其实题在题库里」。

## 搜索

顶部搜索框会同时匹配题干、答案、解析和标签。两个字的词也能搜到（中文按字匹配）。

## 筛选

顶部一张工具条装下了全部筛选条件：

- **学科 / 题型 / 难度 / 来源 / 排序**：下拉可以叠加，任意组合都行。
- **草稿箱**：用页头的「草稿箱」切过去——录入、AI 生成、手工录题都先落成草稿。复核通过才算正式入库。
- **常用标签**：出现在工具条第二行，按题量从多到少排。标签多起来以后，用标签框右边的搜索框输入两个字就能模糊匹配（命中的字会高亮）；默认只显示最常用的十几个，点「展开全部」看其余。点一个标签＝只看带这个标签的题，再点一下取消。
- **已筛选**：命中的条件会变成一行小胶囊列出来，点胶囊上的 ✕ 单独去掉某个条件，「清空全部」一键回到全量。

## 翻页

题目按页显示，列表头会写「共多少道 · 当前第几到第几道 · 第几页」，右侧的 `‹ ›` 可以直接翻页；列表底部是完整的分页条，可以点页码、跳到指定页，也可以把每页改成 20 / 50 / 100 道。翻页后会自动回到列表顶部。

## 草稿箱与复核

录入（截图 / PDF / 文字）、AI 出题、手工录题保存下来的题，都是**草稿**：能搜到、能改，但还没过复核。

- 进「题库 → 草稿箱」逐题或批量「复核通过（入库）」，题目才变成正式状态；
- 「驳回」要写原因，题会退回草稿并带上驳回原因，方便回头改；
- 手工录题时如果不进草稿箱，勾上「我已核对并补齐答案、解析和知识点，直接入库」再保存即可。

草稿允许暂时缺答案、解析或知识点；**直接入库和复核通过前，这三项必须全部补齐**。选择题的答案还要对应实际选项：单选只能选一个答案，多选不能含不存在的选项。

## 编辑

点任意一道题打开右侧详情，再点「编辑」。公式用 `$...$` 包裹，例如 `$x^2+1$`；图片可以直接粘贴到题干框，也可以加在「配图」里。

> 配图会作为附件挂在题目下，原图一直保留，不会被压缩或覆盖。

## 删除

删除是「移到回收站」，题目还在，随时能恢复。彻底删除只对回收站里的题开放，而且同步过的题不允许硬删——否则下次同步会被服务端拉回来。

## 导出

勾选若干题 → 「导出」，两种选法：

- **导出 ZIP（含图片）**：得到一个 `questions.zip`，里面有 `questions.json` 和 `images/`，图片跟着走。导到别的机器、或者再导回本机都能用（同一道题会按原 id 覆盖，不会多出一份）。
- **导出 JSON（只有文字）**：只带题目文字，图片位置写成「【图】」，并把图名记在 `missingImages` 里，导入时会提示补图。

两种格式都能给中心系统或别的智能体读，格式说明见「导入 → 题目包格式」。

## 批次

导入进来的题会记录属于哪一批。导入错了到「导入 → 导入历史」整批撤销，比逐题删快。
