# 听写

把今天的听写清单变成可反复播报的语音，播完保留整批清单供人工核对。全部在本机完成，不需要模型 Key，断网可用。

## 三步流程

1. **放进清单**：选择图片、把图片拖进虚线框，或直接 `⌘V` 粘贴截图。本机 OCR 读出词条；没有图片也可以「手工新建」。
2. **校对词条**：中文词条下面常驻显示拼音。带多音字的行会列出候选读音（如「重」的 `zhòng / chóng`），**必须点选一个读音**才能开始；选完会同步更新显示与发音。读音仍不准时，在「按这个读」里填一个同音字（如把「行」读成 háng 就填「航」），点「试听」确认。
3. **听写与核对**：默认每念完一条隔 5 秒再念下一条。可以暂停、重播、跳到下一条。播完后页面保留**本批完整清单（词条 + 拼音）**，照着逐项核对孩子写的结果——这里不判分、不出报告。

## 快捷键

| 键 | 作用 |
|---|---|
| `⌘⇧N` | 全局：播报下一个（不在听写页时会自动切过去） |
| `⌘⇧R` | 全局：重播这条 |
| `空格` | 播放台内重播当前 |
| `→` | 播放台内下一个 |
| `Esc` | 播放台内结束 |

如果系统里别的软件占用了 `⌘⇧N` / `⌘⇧R`，热键会注册失败，但页面按钮和播放台内快捷键仍然可用。

## 设置（第一步页面里）

- **词条间隔**：默认 5 秒，可改 3 / 8 / 10 秒。计时从念完之后才开始，长单词不会被截断。
- **拼音显示**：带声调 `yín háng` / 数字调 `yin2 hang2` / 无声调 `yin hang`。
- **语速**：慢 / 正常 / 快。

## 已知边界

- 手写或很糊的照片，本机 OCR 可能认不准；校对页会把这类行标成「OCR 需核对」，请逐字看一遍。
- 拼音库按词组优先（如「银行」读 `yín háng`），但覆盖不到所有词；拿不准的一律列候选让人选，不替你猜。
- 语音用的是系统自带音色，中文多音字的读音不一定符合语境；以「试听」结果为准，必要时改「按这个读」。
- 不做语音说「下一个」、不做外部设备指令、不做判分与报告。
