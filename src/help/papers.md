# 试卷

从题库挑题、按标准卷配分、排版打印，全部在本机完成，断网也能用。

## 建卷

「试卷 → 新建试卷」先选一份**标准卷方案**：

- 新高考Ⅰ卷 · 数学（150 分）
- 通用 100 分卷
- 自定义（100 分起）

方案只预填总分与大题结构（单选 8 题 × 5 分……），**不锁定分值**，后面怎么改都行。

## 选题

两条入口：

1. 编辑器左边「+ 从题库选题」，打开一个宽选题窗：默认按本大题的题型预选（单选大题就只看单选题），按创建时间倒序排列，新录的题排在前面；还可以按关键词、学科、难度筛选、分页翻看，多选后加入指定大题。
2. 题库里多选题目 → 「加入试卷」→ 选一份草稿卷与大题。

同一道题不会在一份卷子里出现两次（已在卷内的题会置灰并标「已在本卷」）。题号是渲染时动态生成的，删题后自动重排，不会出现「第 7 题缺失」。

## 按蓝图组卷

不想一题一题挑，就填一张**双向细目表**：每个大题写清「几道题 × 每题几分」，再按易 / 中 / 难分一下，系统从已入库的题里自己抽。

- **先算分再抽题**：Σ(题数 × 每题分值) 必须正好等于卷面总分，差 0.5 分都会拦下来，不会「先抽完再凑」。
- **抽题规则是确定的**：只取已入库的题，本卷用过的不会重复；用过的次数少的优先、新的优先。同一份蓝图配同一个题库，抽出来的是同一套卷。
- **缺题不糊弄**：某一档凑不够就整次放弃，卷子一个字都不改，并列出「哪个大题、哪一档、差几题」；可以点「放宽难度再组一次」，只保证题型与知识点。
- 可以指定**知识点配额**（比如「集合的概念」要 3 题），指定后优先满足，配额用完不再硬顶。
- 组完蓝图会存在卷子里，列表上点「再组一套」就能按同一份蓝图出一份**不撞题的 B 卷 / 补考卷**。

## 换题与撤销

每道题行尾的 ⇄ 是换题：先给候选（同学科、同题型、至少共用一个知识点、已入库、不在本卷），点「换成这道」才真的换。

换题**不动题号、不动分值、不动所属大题**，换完行尾会出现 ↩，点一下就能把原来那道题（含它的旧快照）原样放回。撤销只记最近一次换题。

## 分值：总分固定

四条规则：

1. **总分先定**，落库后就是合同值。要改走「重新设置总分」，并且必须重新配平。
2. **默认按大题统一分值**：改「每题 X 分」，本大题所有题一起重算；大题说明自动生成「本大题共 8 小题，每小题 5 分，共 40 分」，不用手写。
3. **允许逐题微调**：直接改某道题的分值，该大题自动切到「逐题自定」。
4. **差额常驻可见**，顶部一直显示「已分配 148 / 总分 150 · 还差 2 分」；**定稿时强校验**，差 0.5 分也会被拒绝，并告诉你差在哪个大题。系统不会自动把差额塞给最后一道题——分值要印在卷面上，必须由人确认。

## 版面

右栏可调：纸型（默认 A4，可切 A3 / B5 / 8K / 16K）、方向、四边页边距、单栏/双栏、字号、行距、题距、选项列数、解答题留白、装订线、水印。顶部「题目 / 版面」两个按钮可以随时收起或展开左右两栏；切到横向卷面时，右栏会自动收起，把宽度让给卷面，需要调版面时再点「版面」。

**选项列数会按栏宽自动收**：每列至少留 26 mm，所以双栏 A4 里 4 个选项会排成 2×2（不会出现 A B C 一排、D 单独一行的孤项），单栏 A4 仍是 4 列。想更密就手动调「选项列数」。

改完即时反映在中间预览里，重开应用仍然保持。中间预览可以直接上下滚动看完整份卷子，不用先打开「预览 / 打印」。多页卷子在预览里按纸一张张分开，页与页之间留有灰缝。

## 答题卡

答题卡和试卷**分开设计**，试卷只绑定一份模板：

- 试卷列表页点「答题卡模板」打开模板库；内置通用、高考数学、语文、英语、理综、文综几套常见规制，覆盖选择题涂卡、填空横线、解答题答题框等分区。
- 模板可以复制成自定义模板再改：卷头字段、作答须知、单栏 / 双栏、答题分区顺序、每个分区按哪些题型收题、涂卡列数、作答区高度。
- 在试卷右栏「答题卡模板」里选一份即可绑定；换模板只影响答题卡，不改卷面题目与分值。
- 答题卡按卷内实际题号生成，题目增减后自动跟着调整；删除自定义模板后，已绑定它的试卷回退到通用模板。

## 打印

「预览 / 打印」里可以切**学生版**和**教师版**：

- 学生版：解答题按题型自动留白（解答 8 行、填空 3 行），选项列数按栏宽自动定（单栏 4 列、双栏 2×2）。
- 教师版：题目下方直接给答案与解析，卷末另附「参考答案与解析」。

打印走「生成自包含 HTML → 系统浏览器打开」，按 ⌘P 打印或另存为 PDF。HTML 里的公式字体已经内联，换台电脑打开也不会变形。

几条硬约束：

- **答案页强制新开一页**，即使正文最后半页是空的也不接排。
- **答题卡默认附上，纸型跟主卷一致**，栏数、卷头、作答分区由绑定的答题卡模板决定，可以关掉。
- 题目块不跨页；页码「第 X 页 / 共 Y 页」在分页后回填，不依赖浏览器自己的页码。

## 预览的整份页面序列

中间预览与全屏预览都展示**完整页面序列**（每个 `.paper-page` 独立成页，全部同时可见），不再受浏览器分页媒体（`@page` / `page-break-after: always`）按第一页截断的影响。分页只作用于打印：打印走自包含 HTML + 系统浏览器，按整份文件分页成 PDF，样式与预览一致。

## 快照：改题库不影响旧卷

题目加入试卷时会存一份**快照**。之后在题库里改题干、改答案，已定稿的卷子不会跟着变——上周发出去的卷子不该今天变形。

草稿卷如果要同步题库的最新内容，点「同步题库最新」（分值、顺序不变）。定稿的卷子只读，要改先「重新打开」。

## 状态

- **草稿**：可加题、删题、调分、改版面。
- **已定稿**：只读，可打印、可复制为新卷、可归档。
- **已归档**：列表默认隐藏，筛选「已归档」可找回。
- 删除是软删，先进回收站。
